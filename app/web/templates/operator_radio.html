One-time setup

Banano Radio is off because the server has no Spotify app credentials. This part happens once, on this machine.

  1. Open developer.spotify.com/dashboard, sign in with the Spotify account that will play the music, and create an app.
  2. Add this exact Redirect URI to the app: {{ redirect_uri }} It has to match character for character.
  3. Copy the Client ID and Client Secret into your .env as BINGO_SPOTIFY_CLIENT_ID and BINGO_SPOTIFY_CLIENT_SECRET, then restart the server.

The account needs Spotify Premium. Adding to the playback queue is a Premium-only feature, so a free account cannot run the radio.
